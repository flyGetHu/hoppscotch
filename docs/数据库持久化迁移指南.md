# PostgreSQL 数据持久化迁移指南（pg_dump）

> 适用场景：将 Docker 匿名卷中的数据库数据迁移到宿主机绑定目录，便于备份和迁移。

---

## 当前状态

默认部署下，PostgreSQL 数据存储在 Docker 匿名卷中：

```bash
# 查看当前挂载类型（Type 为 volume 表示匿名卷）
sudo docker inspect hoppscotch_hoppscotch-db_1 --format '{{json .Mounts}}' | python3 -m json.tool
```

匿名卷数据在 `down` + `up` 后**不会丢失**，但不便于备份和迁移服务器。

---

## 迁移步骤

### Step 1：完整备份（服务运行中，零影响）

```bash
cd ~/hoppscotch

# SQL 明文格式（可读、可grep）
sudo docker exec hoppscotch_hoppscotch-db_1 \
  pg_dump -U hoppscotch -d hoppscotch --clean --if-exists > backup-$(date +%Y%m%d%H%M).sql

# 自定义压缩格式（体积更小、恢复更可靠）
sudo docker exec hoppscotch_hoppscotch-db_1 \
  pg_dump -U hoppscotch -d hoppscotch -Fc > backup-$(date +%Y%m%d%H%M).dump
```

**验证备份完整性：**

```bash
# 检查文件头尾
head -3 backup-*.sql    # 应包含 "PostgreSQL database dump"
tail -3 backup-*.sql    # 应包含 "PostgreSQL database dump complete"

# 检查 COPY 块数量与结束符一致
grep -c "^COPY" backup-*.sql     # 表数量
grep -c "^\\\.$" backup-*.sql   # 应与上面相同
```

### Step 2：修改 docker-compose.override.prod.yml

确认 `hoppscotch-db` 服务已包含 `volumes` 挂载：

```yaml
hoppscotch-db:
  image: postgres:15-alpine
  ports: []
  volumes:
    - ./postgres-data:/var/lib/postgresql/data  # 数据持久化到宿主机
  environment:
    POSTGRES_USER: hoppscotch
    POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-hoppscotch}
    POSTGRES_DB: hoppscotch
```

### Step 3：停服务（开始停机）

```bash
sudo docker-compose --profile default -f docker-compose.override.prod.yml down
```

确认无 hoppscotch 容器运行：`sudo docker ps`

### Step 4：创建目标目录

```bash
mkdir -p ./postgres-data
sudo chown 70:70 ./postgres-data
sudo chmod 700 ./postgres-data
```

> `70` 是 postgres:15-alpine 镜像中 postgres 用户的 UID。

### Step 5：启动 DB 并验证挂载

```bash
sudo docker-compose --profile default -f docker-compose.override.prod.yml up -d hoppscotch-db

# 等待就绪
until sudo docker exec hoppscotch_hoppscotch-db_1 pg_isready -U hoppscotch; do
  echo "等待数据库启动..."
  sleep 2
done
```

验证挂载类型：

```bash
sudo docker inspect hoppscotch_hoppscotch-db_1 --format '{{range .Mounts}}{{.Type}} {{.Source}} -> {{.Destination}}{{"\n"}}{{end}}'
# 应输出: bind /home/ubuntu/hoppscotch/postgres-data -> /var/lib/postgresql/data
```

### Step 6：导入数据

```bash
BACKUP_FILE=$(ls -t backup-*.sql | head -1)

sudo docker exec -i hoppscotch_hoppscotch-db_1 \
  psql -U hoppscotch -d hoppscotch < "$BACKUP_FILE"
```

导入末尾不应有 `ERROR`（`WARNING` 可忽略）。验证表是否存在：

```bash
sudo docker exec hoppscotch_hoppscotch-db_1 psql -U hoppscotch -d hoppscotch -c "\dt"
```

### Step 7：启动全部服务

```bash
sudo docker-compose --profile default -f docker-compose.override.prod.yml up -d
```

验证：

```bash
sudo docker ps                              # 所有容器运行
curl -f http://<服务器IP>/backend/ping      # "Success"
ls -la ./postgres-data/                      # 宿主机目录有数据
```

### Step 8：清理旧匿名卷（确认一切正常后）

```bash
# 查看旧卷
sudo docker volume ls -q

# 确认无容器使用后删除
sudo docker volume rm <旧卷ID>
```

---

## 回滚方案

如果迁移后发现问题：

```bash
# 1. 停服务
sudo docker-compose --profile default -f docker-compose.override.prod.yml down

# 2. 删除新数据目录
sudo rm -rf ./postgres-data

# 3. 移除 volumes 配置（从 docker-compose.override.prod.yml 中删除 volumes 行）

# 4. 重新启动（Docker 会创建新的匿名卷）
sudo docker-compose --profile default -f docker-compose.override.prod.yml up -d

# 5. 用备份恢复数据
sudo docker exec -i hoppscotch_hoppscotch-db_1 \
  psql -U hoppscotch -d hoppscotch < backup-xxxxxxxxxx.sql
```

---

## 日常备份

持久化后，备份方式有两种：

```bash
# 方式一：pg_dump 逻辑备份（推荐，数据一致性好）
sudo docker exec hoppscotch_hoppscotch-db_1 \
  pg_dump -U hoppscotch -d hoppscotch > backup_$(date +%Y%m%d).sql

# 方式二：直接拷贝宿主机目录（需先停 DB）
sudo docker-compose --profile default -f docker-compose.override.prod.yml stop hoppscotch-db
tar czf postgres-data-backup-$(date +%Y%m%d).tar.gz postgres-data/
sudo docker-compose --profile default -f docker-compose.override.prod.yml start hoppscotch-db
```
