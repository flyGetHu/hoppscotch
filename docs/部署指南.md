# Hoppscotch v2 部署指南（飞书 SSO + 内网 IP 直连）

> 分支：`feature/feishu-sso-login`
> 模式：AIO 单容器 + 子路径访问 + HTTP（防火墙白名单）

---

## 架构

```
浏览器 → HTTP(80) → [AIO 容器 :80 Caddy] → 后端(:8080) + 前端(SPA) + Admin(/admin*)
                        ↓
                  [PostgreSQL 15]  （端口不暴露）
```

- **1 个容器**跑全部服务（后端 + 前端 + Admin + Caddy 反向代理）
- **子路径模式**：所有功能通过一个端口的不同路径访问，只需开放 80
- **安全**：依赖防火墙白名单限制访问来源

---

## 前置条件

| 项目 | 要求 |
|------|------|
| 系统 | Ubuntu 20.04+ |
| Docker | v20.10+ |
| Docker Compose | v1.x 或 v2.x |
| 内存 | 最低 2GB，推荐 4GB |
| 端口 | 开放 **80**（防火墙白名单限制来源 IP） |

### 飞书开放平台

在 [open.feishu.cn/app](https://open.feishu.cn/app) 创建企业自建应用，记录 **App ID** 和 **App Secret**：

| 配置项 | 值 |
|--------|-----|
| 重定向 URL | `http://<服务器IP>/backend/v1/auth/feishu/callback` |
| 权限范围 | `contact:user.base:readonly`、`contact:user.email:readonly` |

> 回调 URL 的 `/backend` 前缀是子路径模式要求的，不能省略。

## 文件清单

部署目录只需这些文件：

```
~/hoppscotch/
├── .env                              # 环境变量（需编辑）
├── Caddyfile.prod                    # Caddy 配置（不动）
├── docker-compose.yml                # 官方 compose（不动）
├── docker-compose.override.prod.yml  # 生产覆盖（不动）
├── setup-feishu.py                   # 飞书 SSO 配置脚本（需编辑）
└── hoppscotch-aio-feishu.tar        # Docker 镜像
```

---

## Step 1：构建镜像（开发机上）

```bash
git checkout feature/feishu-sso-login
docker build -f prod.Dockerfile --target aio -t hoppscotch-aio:feishu .
```

首次约 10-20 分钟（含 Go 编译 Caddy + Node 编译前后端），后续有层缓存会快很多。

---

## Step 2：上传到服务器

```bash
# 导出镜像（原始 tar，跨平台兼容性最好）
docker save -o hoppscotch-aio-feishu.tar hoppscotch-aio:feishu

# 上传所有文件
scp hoppscotch-aio-feishu.tar \
    docker-compose.yml \
    docker-compose.override.prod.yml \
    Caddyfile.prod \
    setup-feishu.py \
    root@<服务器IP>:~/hoppscotch/
```

在服务器上加载镜像：

```bash
cd ~/hoppscotch && sudo docker load < hoppscotch-aio-feishu.tar
```

---

## Step 3：配置 `.env`

在服务器上创建 `~/hoppscotch/.env`（**注意：行首不能有空格**）：

```env
DATABASE_URL=postgresql://hoppscotch:<强密码>@hoppscotch-db:5432/hoppscotch
POSTGRES_PASSWORD=<与上面一致的密码>
DATA_ENCRYPTION_KEY=<32字符密钥>
TRUST_PROXY=true
WHITELISTED_ORIGINS=http://<服务器IP>
VITE_BASE_URL=http://<服务器IP>
VITE_SHORTCODE_BASE_URL=http://<服务器IP>
VITE_ADMIN_URL=http://<服务器IP>/admin
VITE_BACKEND_GQL_URL=http://<服务器IP>/backend/graphql
VITE_BACKEND_WS_URL=ws://<服务器IP>/backend/graphql
VITE_BACKEND_API_URL=http://<服务器IP>/backend/v1
ENABLE_SUBPATH_BASED_ACCESS=true
```

将所有 `<服务器IP>` 替换为实际 IP（如 `129.204.250.29`）。

生成加密密钥：

```bash
openssl rand -hex 16    # 输出 32 字符 hex 字符串
```

**`.env` 注意事项**：
- 行首不能有前导空格，否则 Docker Compose 不识别
- 密钥含特殊字符时 shell 中用单引号包裹
- `DATABASE_URL` 和 `POSTGRES_PASSWORD` 的密码必须一致

## Step 4：启动

```bash
cd ~/hoppscotch

# 检查 Docker Compose 版本
sudo docker compose version 2>/dev/null || sudo docker-compose --version

# v2 (docker compose)
sudo docker compose --profile default -f docker-compose.override.prod.yml up -d

# v1 (docker-compose)
sudo docker-compose --profile default -f docker-compose.override.prod.yml up -d
```

> 以下文档以 **v1** (`docker-compose`) 为例。如果你是 v2，把 `docker-compose` 替换为 `docker compose`。

确认迁移完成：

```bash
sudo docker-compose --profile default -f docker-compose.override.prod.yml logs hoppscotch-migrate
# 看到 "All migrations have been successfully applied" 即成功
```

确认服务运行：

```bash
curl -f http://<服务器IP>/backend/ping    # "Success"
```

## Step 5：配置飞书 SSO

### 准备加密凭据

用 AIO 容器内的 Node.js 对飞书凭据加密：

```bash
sudo docker exec -e DATA_ENCRYPTION_KEY='<你的32位密钥>' hoppscotch_hoppscotch-aio_1 node -e "
const crypto = require('crypto');
const key = process.env.DATA_ENCRYPTION_KEY;
function encrypt(text) {
  const iv = crypto.randomBytes(16);
  const cipher = crypto.createCipheriv('aes-256-cbc', Buffer.from(key), iv);
  let enc = cipher.update(text);
  enc = Buffer.concat([enc, cipher.final()]);
  return iv.toString('hex') + ':' + enc.toString('hex');
}
console.log('CLIENT_ID=' + encrypt('你的飞书AppID'));
console.log('CLIENT_SECRET=' + encrypt('你的飞书AppSecret'));
"
```

记录输出的 `CLIENT_ID=...` 和 `CLIENT_SECRET=...`。

### 执行配置脚本

编辑 `setup-feishu.py`，填入上一步输出的加密值和实际 IP：

```python
# 需要修改的 3 处
FEISHU_CLIENT_ID_ENC = "<上一步输出的CLIENT_ID>"
FEISHU_CLIENT_SECRET_ENC = "<上一步输出的CLIENT_SECRET>"
FEISHU_CALLBACK_URL = "http://<服务器IP>/backend/v1/auth/feishu/callback"
```

执行：

```bash
python3 setup-feishu.py
```

重启使配置生效：

```bash
sudo docker-compose --profile default -f docker-compose.override.prod.yml restart hoppscotch-aio
```

## 踩坑记录

### `.env` 行首空格导致变量不生效

Docker Compose 的 `.env` 解析器要求变量名在行首，前导空格会导致整行被忽略。从文档复制 `.env` 模板时注意去掉缩进。

验证方法：`cat -A .env | head -5`，正常行应该是 `KEY=value$`，不能是 `  KEY=value$`。

### Windows 换行符（`\r`）

从 Windows 创建的 `.env` 文件可能带 `\r\n` 换行符。修复：

```bash
sed -i 's/\r$//' .env
```

### 7z / gzip 跨平台镜像传输失败

Windows 上 `docker save | gzip` 或 `docker save | 7z a -si` 传到 Linux 后加载报 `invalid tar header`。用原始 tar 最可靠：

```bash
docker save -o image.tar image:tag    # Windows
docker load < image.tar               # Linux
```

### Docker Compose v1 vs v2 命令差异

```bash
# v1（旧版，命令带连字符）
sudo docker-compose --profile default -f docker-compose.override.prod.yml up -d

# v2（新版，子命令形式）
sudo docker compose --profile default -f docker-compose.override.prod.yml up -d
```

### override 文件必须显式声明 `image` 和 `env_file`

官方 `docker-compose.yml` 用 `build:` 构建镜像，服务器上没有源码只能用预加载镜像。旧版 Docker Compose v1 的 override 合并时可能丢失 `env_file`，需要显式声明：

```yaml
hoppscotch-migrate:
  image: hoppscotch-aio:feishu       # 覆盖 build，用预加载镜像
  command: ["sh", "-c", "cd /dist/backend && npx prisma migrate deploy"]  # AIO 镜像默认入口是 aio_run.mjs
  env_file:
    - .env                             # 显式声明，防止 override 合并丢失
```

### providers 返回空数组

启动时校验 Provider 的 4 个字段（`CLIENT_ID`、`CLIENT_SECRET`、`CALLBACK_URL`、`SCOPE`）是否都有值，任一为空该 Provider 被移除。确保全部非空。写入配置后必须**重启 AIO 容器**使配置生效。

## 本地开发

本地开发不需要 Docker 部署，直接用 `pnpm dev`：

```bash
docker compose --profile database up -d
pnpm --filter hoppscotch-backend exec prisma migrate deploy
pnpm dev
```

需要在 `packages/hoppscotch-backend/` 下额外创建 `.env`（NestJS 从工作目录加载）：

```env
DATABASE_URL=postgresql://postgres:testpass@localhost:5432/hoppscotch
DATA_ENCRYPTION_KEY=<任意32字符>
WHITELISTED_ORIGINS=http://localhost:3170,http://localhost:3000,http://localhost:3100
TRUST_PROXY=false
VITE_BASE_URL=http://localhost:3000
```
